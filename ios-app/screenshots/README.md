# App Store 用スクリーンショット

App Store Connect の「iPhone」のスクリーンショット欄に、フォルダごとにファイル名の番号の順でアップロードする。
透明なしの PNG。2026-10-26 にアプリの画面をそのまま撮った（記録の数字は見本）。

| フォルダ | 大きさ（横×縦 px） | 入れる欄 |
|---|---|---|
| `6.7/` | 1290 × 2796 | 6.9インチ（または 6.7インチ）ディスプレイ |
| `6.5/` | 1242 × 2688 | 6.5インチディスプレイ |
| `5.5/` | 1242 × 2208 | 5.5インチディスプレイ |

| 番号 | 画面 |
|---|---|
| 1-home | ホーム（今日のルール No.23・連続日数・練習の★1〜★3・記録帳と図鑑の入口） |
| 2-play | 調査の途中（のこる候補のメーター「3通り −1」、合う／合わないの山、予想が外れた「発見！」の瞬間） |
| 3-judge | 判定テスト（候補を1つに絞ったあと、5枚に○×で答えている途中） |
| 4-result | 結果（見抜いたルール・★3・調べ／判定／発見の回数・45枚の○×、下に「ふり返り」が続く） |
| 5-tutorial | はじめての調査 第2話（下の帯の案内「×になるカードも試してみよう」） |
| 6-zukan-dark | ルール図鑑（ダークテーマ。標本箱と見抜いたルールの一覧） |

- **日替わりの答えは見せていない**: 3-judge・4-result は練習の問題（★2）。2-play は今日のルールの途中まで（候補が3つ残っていて、答えは決まらない）。図鑑の見本の記録は「練習で見抜いた」ことにして、日替わりの No. と答えを結びつけていない
- 撮り方: Google Chrome の画面なしモードを DevTools Protocol で動かし、ローカルに開いたアプリ（このフォルダの2つ上の `index.html`）を、画面の大きさ 430×932（6.7）・414×896（6.5）・414×736（5.5）、拡大率3倍で撮った。端末の時計は 2026年11月11日（水）8:30 に合わせ、記録は見本の値（連続6日・最高9日・解決19・図鑑31）を入れた。音は消してから操作した。文字の行が画面の端や下の帯で半分に切れないよう、数px だけ送ってから撮った
- 画面を大きく変えたときは撮り直す
