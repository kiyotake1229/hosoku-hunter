## 変更内容

### 1. アイコン（`icon.svg` と PNG）

- 図柄: 夜の調査ノート（ダークの地の色 `#0E1512`〜`#2A3B32`、点の方眼）に、標本カードを2枚（奥 = 赤い丸、手前 = 青い三角。青はアプリのカードと同じ斜線の模様。手前のカードは標本ラベルの二重枠）と、黄色い虫眼鏡（`#F2D04B`）。虫眼鏡のガラスの中は、下のカードとノートを 1.45 倍に描く。ホーム左上のロゴ（白いカード・青い三角・黄色い虫眼鏡）と同じ組み合わせ
- 角丸なし（OS が付ける）。四隅まで地の色で塗り、透明な部分は無い
- カードと虫眼鏡は中心から半径 400px 以内（1024px のとき）。Android の丸いマスクの安全域（半径 409.6px）に収まるので、同じ PNG を `any` と `maskable` の両方に使う
- 文字を使わない（書体が無い環境でも同じ絵になる。アイコンの書き出しに通信が要らない）
- 180px（iOS の角丸）・192px（丸いマスク）・120px・60px・40px・29px に縮めて、カード2枚と虫眼鏡が見分けられることを目で確かめた

書き出し（このフォルダで実行。Google Chrome・Python 3 と Pillow。OGP は書体を読むための通信も要る）:

```bash
python3 tools/make-images.py          # アイコンと OGP の両方
python3 tools/make-images.py icons    # アイコンだけ（iOS の起動画面の元も作り直す）
python3 tools/make-images.py ogp      # OGP 画像だけ
python3 tools/make-images.py splash   # iOS の起動画面の元だけ
```

- 段取り名人の `tools/make-images.py`（iOS の起動画面の元を作る `splash` まで）と同じ形。Chrome の画面なしモードで 1024px を1回だけ描き、Pillow で 512 / 192 / 180 に縮める。すべて透明なし（RGB）
- Chrome を待つのは最長90秒（`TIMEOUT`）。「bytes written to file」が出たら Chrome を終わらせる。終わらなければ terminate → kill（どちらも `timeout` 付き）で止め、失敗として終わる
- 検査: 下地の赤紫（描けなかった印）が出ていないか、安全域の中にカードの白・三角の青・丸の赤・虫眼鏡の黄があるか、四隅が地の色（暗い緑）か。OGP は書体が読めないと赤紫になり、書き出さずに止まる
- 起動画面の元の地の色はアプリの紙面（ライト `#ECEFEA`・ダーク `#0F1513`）
- 作業用のファイル（Chrome のプロファイル・描く HTML）は一時フォルダに作って消す

### 3. `sw.js`（Service Worker）

段取り名人の `sw.js` と同じ作り。名前の頭を `hosoku-` にした。

| 対象 | やり方 |
|---|---|
| 先にキャッシュ（install） | `./`・`index.html`・`manifest.json`・`icon-192.png`・`icon-512.png`・`apple-touch-icon.png`・`support.html`。HTTP のキャッシュを通さずに取る（`cache: 'reload'`） |
| ページ | **ネット優先**。取れたらキャッシュを新しくする。オフライン・5xx・4秒たっても返事が無いときはキャッシュ。`?` と `#` は無視して探す。キャッシュに無いページの代わりに `index.html` を出すのはアプリのページ（`./` と `./index.html`）だけ。Navigation Preload を使う（対応ブラウザだけ） |
| 同じ場所のほかのファイル | キャッシュ優先 |
| 書体の CSS（fonts.googleapis.com） | stale-while-revalidate（`<link>` で読む opaque の応答も入れる） |
| 書体のファイル（fonts.gstatic.com） | キャッシュ優先。上限400件（超えたら古いものから消す） |
| 古いキャッシュ（activate） | 名前が `hosoku-` で始まり、いまの版でないものだけ消す。同じ github.io の兄弟アプリ（段取り名人 `dandori-`・嘘つき村 `usotsuki-` など）のキャッシュには触らない |
| ほかのアプリに消されたとき | ページを開くたび（通信できるとき）に、先にキャッシュするファイルのうち無くなったものだけを取り直す（`refill`） |
| 受け持つ範囲 | このアプリのスコープ（`/hosoku-hunter/`）の中と Google Fonts だけ。同じドメインのほかのアプリ（`/dandori-meijin/`・`/usotsuki-mura/` など）の読み込みには触らない |

キャッシュの名前: `hosoku-app-v1`（アプリ）、`hosoku-fonts-v1`（書体。アプリの版を上げても消さない）。

版の上げ方:

- `index.html`・`support.html` を直しただけ → 何もしない（ページはネット優先なので、次に開いたときに届く）
- `manifest.json`・アイコン・先にキャッシュするファイルの一覧を変えた → `sw.js` の `VERSION` を1つ上げる（いまは `v1`）
- 書体の指定を変えた → `FONT_CACHE` を `hosoku-fonts-v2` に

### 6. `index.html` に足したもの

#### `<head>`

- theme-color（ライト `#ECEFEA`・ダーク `#0F1513`、`media` 付き。前からあった）、`mobile-web-app-capable`・`apple-mobile-web-app-capable`・`apple-mobile-web-app-title`（法則ハンター）・`apple-mobile-web-app-status-bar-style`（`default`。`black-translucent` だとライトの紙面で時計の文字が読めないため。段取り名人と同じ）、`canonical`、OGP・Twitter カード（画像は絶対 URL）。説明文は前のまま

#### ネイティブ連携（Capacitor の iOS アプリのときだけ。Web ではどれも何もしない）

- 判定（`// ==NATIVE START==`〜`END`）: `NATIVE`（`window.Capacitor.isNativePlatform()` が true。判定が例外でも false）、`CAP`（`window.Capacitor.Plugins`）、`plug(名前)`（ネイティブでプラグインがあるときだけそのオブジェクト）、`quiet`（Promise の失敗を外に出さない）、`FRAMED`（iframe・origin の無い sandbox・親を読めない iframe。前からあったものをこの目印の中へ移した）。プラグインは import せず `window.Capacitor.Plugins` から使う
- 使うプラグインとメソッド

| プラグイン（npm） | メソッド | 使う場面 |
|---|---|---|
| Haptics（`@capacitor/haptics`） | `impact({ style: 'LIGHT' })` / `impact({ style: 'MEDIUM' })` / `impact({ style: 'HEAVY' })` / `notification({ type: 'WARNING' })` / `notification({ type: 'SUCCESS' })` | 色・形・数を選ぶ・設定の切り替え / 調べた（答えがめくれた） / 発見（予想が外れた。調べたときの振動とは重ねない） / 判定が外れた / 解決。設定の「振動」OFF で止める |
| Preferences（`@capacitor/preferences`） | `get({ key })` / `set({ key, value })` | 記録の二重保存。キーは localStorage と同じ `hosoku.v1` |
| LocalNotifications（`@capacitor/local-notifications`） | `getPending()` / `cancel({ notifications })` / `checkPermissions()` / `requestPermissions()` / `schedule({ notifications })` / `addListener('localNotificationActionPerformed')` | 毎朝の通知・通知を押して開く |
| App（`@capacitor/app`） | `addListener('appStateChange')` | 裏に回ったら止めて保存、戻ったら日付の確かめ・通知の予約し直し・状態バーの当て直し |
| StatusBar（`@capacitor/status-bar`） | `setStyle({ style })` | 状態バーの文字色を画面の色に合わせる（ダーク = `DARK`、ライト = `LIGHT`、自動 = `DEFAULT`）。起動時・0.9秒後・色を変えたとき・端末の外観が変わったとき・アプリに戻ったとき |

- **記録の二重保存**（`// ==STORE START==` の中）: 保存のたびに localStorage と Preferences に同じ JSON を書く（`persist` → `prefsSave`）。起動時は `nativeRestore` で Preferences を読み、次の決まりでそろえる
  - localStorage が空・壊れている・**開いたときに空だった**（`blankAtStart`）、または Preferences のほうが新しい（`t` が大きい）→ Preferences から戻す（localStorage にも書き戻す）
  - localStorage のほうが新しい・Preferences が空 → Preferences に書いて追いつかせる
  - 新しい版のアプリが保存した記録（v が2以上）は、どちらにあっても読まず、上書きもしない
  - **戻す順**: Preferences を読み終えるまで（`restoring`）は Preferences に書かず、「記録が空なら既定の形を保存」（`persistIfEmpty`）もしない。起動（`boot`）は読み終えてから（最長1.2秒待つ。遅れたら先に起動し、読み終えたら描き直す）。起動までは画面を押せない（`booted`）。こうしないと、OS が localStorage を消したあとの起動で、空の記録（時刻が新しい）が Preferences の記録を上書きしてしまう
- **毎朝の通知**（設定「毎朝の通知」と「知らせる時刻」。初めは OFF・7:00）: 題「今日のルールが届きました」、本文「No.3（難しさ★★☆・候補99通り）。カードに隠れたルールを見抜こう。」。**答えのルールは書かない**（ロック画面に出るため。`check-app` が60日分で確かめる）。今日から28日分を1日ずつ予約（時刻を過ぎた分は入れない）。通知の番号は `820000 + No.`（段取り名人は 810000）。予約し直すときは、この番号の範囲の予約だけを取り消してから入れ直す（起動・アプリに戻ったとき・設定を変えたとき）。**許可を求めるのは ON にしたときだけ**（断られたら OFF のまま、設定の行に「通知が許可されていません。iPhone の「設定」→「通知」→「法則ハンター」で許可できます。」）。予約し直しでは許可の状態を確かめるだけ。通知を押すと今日のルールを開く（起動前に届いたものは起動のあと）。**Web では設定の行を出さない**（LocalNotifications があるときだけ）
- **裏に回ったとき**（`pauseAll` / `resumeAll`。ブラウザは `visibilitychange`、iOS アプリは App の `appStateChange` でも）: 調べている途中を保存し、音（AudioContext）を止める。iOS アプリでは裏に回っている間を `away` で持ち、`ensureAudio`・`buzz`・`discover` が音・触覚・発見の演出を出さない（WebView では `document.hidden` が変わらないことがあるため。ブラウザは今までどおり `document.hidden` で止まる）。めくり・メーターの数え下げのタイマーは止めずに最後の形まで進める（戻ったときに途中の形で止まっていない）。戻ったら日付を確かめる
- 設定: iOS アプリでは振動の説明「調べる・発見・解決・判定の外れで軽く震える」、保存先「この端末のアプリの中」。いちばん下に「サポート・プライバシーポリシー」のリンク（`https://kiyotake1229.github.io/hosoku-hunter/support.html`、別のタブ）。通知のスイッチも、押したあと焦点をスイッチに残す

#### Service Worker の登録（`registerSW`）

`boot()` の最後で呼ぶ。登録しないのは、iOS アプリの中（`NATIVE`）／Claude Artifact のような iframe・sandbox の中（`FRAMED`）／http(s) 以外（file: など）／安全でない接続／Service Worker の無いブラウザ。画面の読み込みが終わってから（`load` のあと）登録し、失敗しても何もしない。

## 既知の注意点

- 同じドメイン（kiyotake1229.github.io）のほかのアプリの中には、activate で「自分以外のキャッシュを全部」消すものがある（嘘つき村の #0013）。消された直後に通信なしで開くと開けない。一度つながった状態で開けば `refill` で戻る
- 日本語の書体は文字のまとまりごとのファイルに分かれていて、表示した文字のファイルだけを読む。オフラインで初めて出る文字は、端末の書体で出ることがある
- ローカル（127.0.0.1）でも Service Worker は登録される。ローカルで確かめたあとは登録を解除しておく（`check-ui` は一時フォルダのプロファイルなので残らない）
- iOS アプリで裏に回ったとき、めくり・メーターの数え下げのタイマーは止めない（音・触覚・発見の演出だけ出さない）。戻ったときに途中の形で止まらないようにするため
- `support.html` の「iOS アプリ版は準備中です」は、App Store に出たら直す
