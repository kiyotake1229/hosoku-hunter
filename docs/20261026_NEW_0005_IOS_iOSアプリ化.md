## 概要

Web アプリ本体（`index.html`）をそのまま同梱する iOS アプリのプロジェクト `ios-app/` を、段取り名人の `ios-app/` と同じ形で Capacitor 7 で作った。Bundle ID は `work.ltv.hosoku`、表示名は「法則ハンター」、iPhone・縦向きのみ。`index.html` が使う5つのプラグイン（App・Haptics・LocalNotifications・Preferences・StatusBar）を入れ、`Info.plist`・プライバシーマニフェスト・アイコンと起動画面、App Store 用のスクリーンショット（3サイズ×6枚）、岩崎さん向けの `ios-app/岩崎さんへの引き渡し手順.md` をそろえた。手元の Mac には Xcode が無いので、ビルドの確認は GitHub Actions の macOS（macos-26・Xcode 26）で行う。
`index.html` と推理エンジンは変えていないので、**問題は変わらない（VERSION 3 のまま）**。

### 5. iPhone 専用にした（`TARGETED_DEVICE_FAMILY = 1`）

段取り名人・嘘つき村と同じ理由（申請に iPad のスクリーンショットが要らない／iPad で縦向きだけにする `UIRequiresFullScreen` は iPadOS 26 で非推奨／画面は中央 480px の1列）。iPad では iPhone 用の画面のまま動く。iPad 対応にするときは `TARGETED_DEVICE_FAMILY` を `"1,2"` に戻し、`UISupportedInterfaceOrientations~ipad` を足し、iPad のスクリーンショットを用意する。

- **UIScene**: Capacitor 7 の雛形のままで UIScene に対応していない。Xcode 27 でビルドすると起動しないおそれがあるので、当面は Xcode 26 でビルドする（CI も Xcode 26）。2027年4月ごろまでに対応する（段取り名人・嘘つき村と同じ。岩崎さんの Mac が macOS 27 なら前倒し）
- **問い合わせ用のメールアドレス**: `support.html` の連絡先は GitHub の Issues だけ。清武さんがアドレスを決めたら、`support.html` のお問い合わせとプライバシーポリシーに足す（それまで申請しない）
- **起動直後の色**: WebView の背景はライトの地の色（`#ECEFEA`）1色。端末がダークのとき、起動画面（暗い緑）からホームに切り替わる一瞬に明るい色が見える可能性がある。実機で確かめる
- **書体の通信**: 書体は Google Fonts から読む（オフラインでは端末の書体）。「データを収集しません」はこのままで出せる見込み。完全に通信をなくすなら、書体（Klee One・M PLUS 2・Courier Prime。どれも SIL OFL）を同梱する改修をする
- **support.html の「iOS アプリ版は準備中です」**: App Store に出たら直す
- **公開リポジトリの中身**: リポジトリは public なので、`docs/`（工数・手元のパス）と `ios-app/岩崎さんへの引き渡し手順.md` は github.com のリポジトリの画面で誰でも読める（公開サイトでは `_config.yml` で隠している）。段取り名人・嘘つき村と同じ扱いで、清武さんの判断を待つ
